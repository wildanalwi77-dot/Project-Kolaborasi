Perhitungan Harga Produk

Penyelesaian menggunakan metode SPLDV

Lihat Rumus

Misalkan:
x = harga 1 jam dinding dari keyboard bekas
y = harga 1 penyiram tanaman otomatis

Dari flyer:
Paket 1:
x + 2y = 120.000
Paket 2:
3 jam dinding + 2 penyiram = Rp290.000
3x + 4y = 290.000

Diketahui:
x + 2y = 120.000 | x 2
3x + 4y = 290.000 | x 1
2x + 4y = 240.000
3x + 4y = 290.000 (dikurangi)
x = 50.000
(Substitusi kan dengan persamaan 1)

x + 2y = 120.000
50.000 + 2y = 120.000
2y = 120.000 - 50.000
2y = 70.000
y = 70.000 ÷ 2
y = 35.000

Jadi,
- Harga 1 jam dinding dari keyboard bekas = Rp50.000
- Harga 1 penyiram tanaman otomatis = Rp35.000

1x =28.000

56.000 + y = 91.000
